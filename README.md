# Higiene Ocupacional | Ruta de aprendizaje

Guía web interactiva de **La Movida de SST Plus** para comprender la higiene ocupacional y estudiar progresivamente las normas venezolanas COVENIN relacionadas con ruido, iluminación, calor y frío, vibración, ventilación y agentes químicos.

## Contenido

- Las 6 Movidas de la Higiene Ocupacional.
- Diagnóstico inicial con retroalimentación.
- Método de lectura de una norma en ocho capas.
- Ruta modular de normas COVENIN.
- Microlearning y retos para grupos de WhatsApp.
- Caso práctico multiexposición.
- Fuentes oficiales y advertencias sobre vigencia y obligatoriedad.
